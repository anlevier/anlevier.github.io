### Overview

Adds a `sampleDescription` field to the launch and setup pages. Clients can optionally enter custom sampling instructions on the launch page (shown only when "Custom Sample Instructions" is selected); admins can edit it post-launch in a new "Sampling" section on the setup page. The field is excluded from the client-facing status page.

### Changes

- Launch draft composition — add `sampleDescription` to the GraphQL query
- Launch page — new Sampling Information section with Standard Sampling / Custom Sample Instructions radio toggle, text area, and character counter
- Setup GraphQL fragment — add `sampleDescription` to the admin query only (excluded from the client query so it stays off the status page)
- Setup constants — add a `sampling` section
- Setup page — register the new Sampling setup child component
- New setup section component with Standard/Custom toggle and editable text area wired to the pending-changes store
- Shared presentational radio toggle used by launch and setup
- Component unit tests covering toggle behavior, text-area visibility, merge calls, and disabled states

- Setup page (admin): Sampling section visible, editable, saves via pending changes
- Status page: confirm `sampleDescription` is absent
